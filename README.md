#  Cookie Clicker Bot (YOLOv8 + ONNX)

Автоматический бот для игры Cookie Clicker на базе нейросети YOLOv8.

##  Возможности

-  Автоматически кликает по печеньке
-  Покупает улучшения
-  Собирает бонусы
-  Закрывает рекламу
-  Остановка по пробелу
-  Рандомные колдауны (имитация человека)

##  Установка

```bash
pip install -r requirements.txt
